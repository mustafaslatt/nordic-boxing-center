# Nordic Boxing Center

Сайт боксёрского клуба в Кристиансанне (Норвегия) с онлайн-записью: вход через BankID, электронный договор, ежемесячная оплата через Vipps или карту и админка для клуба.

Тексты и данные взяты с [nordicboxingcenter.no](https://www.nordicboxingcenter.no).

## Возможности

- **Сайт** — предложения клуба, расписание, цены, контакты (серо-тёмно-синий дизайн, адаптивный).
- **Запись** (`/bli-medlem.html`) — выбор тарифа → BankID → договор → оплата → подтверждение. Онлайн-запись только с 18 лет.
- **Оплата** — Vipps Recurring (соглашение + ежемесячные списания) или карта через Stripe (подписка).
- **Договоры** хранятся в SQLite: текст, SHA-256, время подписи, данные BankID. Fødselsnummer не сохраняется.
- **Админка** (`/admin`) — обзор, участники, платежи, отмена договора, цены и условия, журнал действий, экспорт в CSV.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env   # укажите ADMIN_EMAIL и ADMIN_PASSWORD
npm start              # http://localhost:5178
```

Пока ключи BankID / Vipps / Stripe в `.env` не заполнены, эти сервисы работают в **тестовом режиме** (имитация, без реальных денег). Для тестового BankID есть синтетические тестовые персоны. С `NODE_ENV=production` сервер не запустится без всех ключей.

## Структура

```
server.js              Express-сервер
src/config.js          настройки из .env
src/db.js              SQLite-схема
src/billing.js         активация, ежемесячные списания Vipps, отмена
src/providers/         BankID (Criipto), Vipps, Stripe
src/routes/            запись, админка, вебхуки, тестовые страницы
public/                сайт, мастер записи, админка
```

## Перед запуском в работу

1. Заключить договоры и получить ключи: [Criipto](https://www.criipto.com) (BankID), [Vipps MobilePay](https://portal.vippsmobilepay.com) (Recurring), [Stripe](https://stripe.com).
2. Разместить на хостинге с HTTPS и постоянным диском для `data/` (например, Render или Fly.io).
3. Проверить текст условий договора (черновик) — редактируется в админке.
